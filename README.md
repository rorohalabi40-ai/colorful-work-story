# Colorful Work Story

أريد منك أن تقوم بتصميم معرض أعمال يكون فيه الـ CV وأيضًا أحد أعمالي. سأرسل لك الرابط بعد قليل.

وأريد أن يكون معرض عملي هذا مرتبًا ومنسقًا بطريقة احترافية أيضًا، وبألوان زاهية وجميلة جدًا وملفتة حتى يُفضل المتصفح عملي ويتحمس أيضًا لرؤيتها.
